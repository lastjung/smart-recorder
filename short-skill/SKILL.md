## 2. 동영상 소스 탐색

- **탐색 방식**: 작업을 시작할 때 반드시 **새로운 별도 윈도우(New Window)**를 열어 사용자 창과 격리한다. 모든 탭은 이 전용 윈도우 내부에서만 관리한다.
- **수량 확보**: 50초 숏츠 영상 제작을 위해, **최종 분량의 1.5배 이상 (최소 5~10개 클립, 총 80초 이상)**의 소스를 충분히 확보하여 편집 유연성을 높인다.
- **종료 방식 (절대 안전 원칙)**:
  1. **Page ID 대조**: 자신이 생성한 고유 Page ID 목록과 일치하는 탭만 선별하여 종료한다.
  2. **정밀 타격**: 광역 종료 명령어(`pkill`, `close all windows`)는 절대 금지한다.
  3. **사용자 보호**: 본인이 열었는지 확실치 않은 탭이나 윈도우는 절대로 건드리지 않고 사용자에게 확인을 요청한다.

- **활성 탭 제한 (엄격 준수)**:
  1. **최대 3개 제한**: 브라우저 내 활성 탭은 **최대 3개**까지만 허용한다.
  2. **즉시 정리**: 목적 달성(다운로드 완료) 혹은 무효 페이지(404, 차단 등) 확인 시 즉시 해당 탭을 종료한다.
  3. **순차 진행**: 탭이 3개를 초과할 경우, 새로운 탭을 열기 전 반드시 기존 탭을 우선 정리한다.

- **사전 승인 사이트**: 아래 목록의 사이트들은 작업 시 별도의 허락 없이 즉시 오픈하여 탐색할 수 있다. (단, 종료 규칙 준수)
  - _고전/빈티지_: **Archive.org, Pond5 Public Domain, Prelinger Archives**
  - _현대/시네마틱_: **Pexels, Pixabay, Mixkit, Coverr**
- **상태**: 허락없이 자동 진행한다

## 4. 제목 및 스크립트 제작

- **방침**:
  1. **스크립트**: 시청자의 시선을 끌 수 있는 제목과 영상 내 텍스트/자막을 구성한다.
     - **대화식 권장**: 단조로운 독백보다는 **2인 이상의 캐릭터가 서로 티키타카(Dialogue)하는 방식**을 적극적으로 사용한다. 연기 톤과 성별을 다르게 설정하여 몰입감을 높인다.
  2. **나레이션 (TTS)**: **Edge-TTS** 또는 **Google TTS** 방식을 사용하여 자연스러운 음성(`mp3`)을 확보한다.
     - **다양한 목소리**: 캐릭터별로 악센트(en-GB, en-US 등)를 다르게 주거나 FFmpeg의 `asetrate` 필터를 활용하여 **남자 목소리, 개성 있는 목소리 등으로 변조**하여 사용한다.
     - **권장 보이스**:
       - `en-US-RogerNeural`: 권위적이고 낮은 보스 목소리.
       - `en-US-GuyNeural`: 에너지 넘치고 쾌활한 목소리.
       - `en-GB-SoniaNeural`: 고양이 캐릭터용 정중하면서도 심술궂은 여성 목소리. (고양이는 여성 목소리 권장)
  3. **자막**: 나레이션과 싱크를 맞춘 `.srt` 파일을 생성하고, FFmpeg를 사용하여 영상에 **Hardsub(영구 자막)** 형태로 삽입한다.
  4. **시청각 일치 (Lip-Sync & Character Consistency)**: **[중요]** 나레이션(음성)과 화면에 보이는 인물/캐릭터는 반드시 일치해야 한다.
     - **다중 배역(2인 이상)**: 캐릭터가 서로 대화(티키타카)할 때는 목소리가 바뀔 때마다 화면의 인물 클립도 즉시 해당 캐릭터로 전환되어야 한다. (예: AI가 말할 때는 로봇 화면, CEO가 말할 때는 CEO 화면)
     - **교차 편집**: 대화의 흐름에 맞춰 영상 소스를 정밀하게 컷 편집하여 시청자가 누가 말하고 있는지 혼동하지 않게 한다.
- **상태**: 허락없이 자동 진행한다

## 5. 영상 합성 및 최종 편집

- **방침**: FFmpeg을 활용하여 최종 해상도로 합성한다.
- **영상파일**: 모든 영상 파일은 인위적로 반복, 속도조절등으로 시간을 늘리지 않는다.
- **오디오파일**: 모든 오디오 파일은 인위적로 반복, 속도조절등으로 시간을 늘리지 않는다.
- **오디오합성**: 배경음악(BGM)은 나레이션을 방해하지 않도록 Volume 0.1~0.3 수준으로 낮추고(Ducking), 나레이션은 Dynamic Normalization을 적용하여 명료하게 만든다.
- **파일제목**: 모든 영상 및 소리의 파일제목은 내용과 일치하게 붙인다. short_final.mp4 같은 일반적인 파일제목은 절대 사용하지 않는다.
  - **레이아웃 규격 (Layout Specs)**:
    - **메인 영상**: 상단 **80% (Top 1024px)** 영역을 사용한다. (720x1024)
    - **영상 처리**: 원본 영상을 **Center Crop**하여 빈 공간 없이 꽉 채운다. (옆면 잘림 허용)
    - **자막 영역**: 하단 **20% (Bottom 256px)** 및 영상 일부를 포함하여 여유롭게 사용한다.
  - **제목 (Title)**:
    - 위치: 상단 여백 (**MarginV=100**)
    - 색상: **Sky Blue (하늘색, &H00FFFF00)**
    - 크기: **Fontsize 40** (단위: Pixels)
  - **자막 (Subtitle)**:
    - 위치: 하단 완전히 밀착 (**MarginV=45**) - _조금 더 내림_
    - 색상: **Yellow (노란색, &H0000FFFF)**
    - 크기: **Fontsize 14** (단위: Pixels)
    - 스타일: **BorderStyle=1 (Outline)**, No Box.
- **상태**: 허락없이 자동 진행한다

## 8. veo 동영상 의뢰 및 예약 (AI Video Generation Preparation)

- **프로세스**:
  1. **스틸컷 준비**: 영상의 핵심 분위기를 담은 스틸컷 3장을 선정하여 준비한다 (Download + nanobanana 사용).

  3. **저장 위치**: 프로젝트 내 `veo` 서브폴더에 저장한다.
  4. **즉시 이동**: 저장 완료 후 주인에게 알림만 남기고 즉시 Step 5(합성)로 진행한다.

## 10. FFmpeg 상세 가이드 (Technical Reference)

에이전트(크로우 등)는 FFmpeg 합성 시 다음 기술적 규칙을 반드시 준수한다.

### 1. 스트림 복제 (Split) 필터 사용
- **규칙**: FFmpeg에서 하나의 입력 영상 스트림을 여러 개의 필터(예: 여러 번의 xfade)에 사용할 경우, 반드시 `split` 필터로 스트림을 복제해야 한다.
- **잘못된 예**: `[vh][vc]xfade... [xf1][vh]xfade...` (이미 사용된 [vh]를 재사용하면 에러 발생)
- **올바른 예**: `[0:v]split=2[v0a][v0b]; [v0a][1:v]xfade... [xf1][v0b]xfade...`

### 2. 해상도, FPS 통일 및 구도 조정 (Framing)
- **규칙 1**: `xfade` 등 여러 영상을 섞는 필터 사용 전, 반드시 모든 입력 영상의 해상도(`720:1280`)와 프레임 레이트(`fps=30`)를 통일해야 한다.
- **규칙 2 (상단 여백 제거)**: 원본 소스의 상단 1/3이 불필요한 빈 공간(예: 천장)일 경우, `crop=iw:ih*2/3:0:ih/3`를 사용하여 상단을 제거하고, `pad=720:1280:0:0:black`을 사용하여 영상을 상단에 배치한다. 이 결과로 하단에 검은 여백이 발생하며, 이는 모바일 시청 환경에 최적화된 구도이다.

### 3. 표준 합성 샘플 코드 (Reference)
```bash
ffmpeg -y \
  -stream_loop -1 -i input1.mp4 \
  -stream_loop -1 -i input2.mp4 \
  -i audio.mp3 \
  -filter_complex \
  "[0:v]scale=720:-1,crop=iw:ih*2/3:0:ih/3,pad=720:1280:0:0:black,fps=30,split=2[v0a][v0b]; \
   [1:v]scale=720:1280:force_original_aspect_ratio=increase,crop=720:1280,fps=30,split=2[v1a][v1b]; \
   [v0a][1:v]xfade=transition=fade:duration=0.5:offset=4[xf1]; \
   [xf1][v0b]xfade=transition=fade:duration=0.5:offset=10[xf2]; \
   [xf2][v1b]xfade=transition=fade:duration=0.5:offset=25[v_nosub]; \
   [v_nosub]subtitles=filename='sub.srt':force_style='Alignment=2,MarginV=45,Fontsize=14,PrimaryColour=&H0000FFFF,BorderStyle=1'[v]" \
  -map "[v]" -map 2:a -t 40 -c:v libx264 -pix_fmt yuv420p output.mp4
```
